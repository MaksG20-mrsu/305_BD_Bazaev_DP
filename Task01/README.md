# Лабораторная работа 1. Подготовка окружения для выполнения заданий и интерактивной работы с СУБД SQLite

## Структура файлов данных

В данной папке находятся следующие файлы:

### Исходные данные
Файлы, скопированные из каталога `dataset`:
- `ratings.csv` - исходный файл с данными об оценках пользователей.
- `movies.csv`, `genres.txt`, `occupation.txt`, `tags.csv`, `users.txt`.

### Файлы, созданные в ходе выполнения работы
- `ratings_count.txt` - файл с результатами анализа: минимальный и максимальный ID пользователя и количество их оценок.
- `sqlite.txt` - информация об установленной версии SQLite и доступных режимах вывода.

### Режимы вывода данных в утилите sqlite3

Доступные режимы вывода:
- `ascii` - вывод в формате ASCII с разделителями
- `box` - вывод в виде таблицы с рамками
- `c` - сокращенный режим (column)
- `column` - вывод в виде выровненных колонок
- `count` - вывод только количества строк
- `csv` - вывод в формате CSV (через запятую)
- `html` - вывод в виде HTML-таблицы
- `insert` - вывод в виде SQL INSERT-операторов
- `jatom` - вывод JSON-атомов
- `jobject` - вывод JSON-объектов
- `json` - вывод в формате JSON
- `line` - вывод по одной записи на строку (ключ = значение)
- `list` - вывод через разделитель (по умолчанию в старых версиях)
- `markdown` - вывод в формате Markdown-таблицы
- `off` - отключение вывода
- `psql` - вывод в стиле PostgreSQL
- `qbox` - вывод в виде таблицы с рамками (режим по умолчанию в новых версиях)
- `quote` - вывод значений в SQL-литералах
- `split` - вывод с разделителями
- `table` - вывод в виде ASCII-таблицы
- `tabs` - вывод через табуляцию
- `tcl` - вывод в формате Tcl-списка
- `batch` - пакетный режим вывода
- `tty` - режим для терминала
