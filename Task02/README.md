# Лабораторная работа 2. Подготовка скриптов для создания таблиц и добавления данных

## Требования к окружению
Для корректной работы скрипта `db_init.bat` на компьютере должны быть установлены:
1. **Python 3.x** (добавлен в системную переменную PATH).
2. **SQLite3** (утилита командной строки `sqlite3` должна быть доступна из терминала).

## Описание процесса
1. Скрипт `make_db_init.py` считывает исходные CSV-файлы (`movies.csv`, `ratings.csv`, `tags.csv`, `users.csv`).
2. Генерируется файл `db_init.sql`, содержащий команды `DROP TABLE IF EXISTS`, `CREATE TABLE` и `INSERT INTO` для всех записей.
3. Скрипт `db_init.bat` последовательно запускает генератор и исполняет полученный SQL-скрипт, создавая и заполняя базу данных `movies_rating.db`.
